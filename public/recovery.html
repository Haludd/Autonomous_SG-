How coordination works

Every option is checked against hard constraints first. Each independent agent gives one ACCEPT, COUNTER (efficiency objection), or VETO (hard constraint) and a 0–100 efficiency score. Acceptance requires no domain breach and a score of at least 70. Scores are disclosed policy calculations. In live mode, Claude provides decisions and rationale; code enforces the acceptance threshold and hard constraints.

Rank: hard-valid options, then fewer stranded chained arrivals, acceptance count, lowest agent score, average score, knock-on cost and arrival delay. Chain checks are system assessments alongside the three agents. One turn contains one structured message from each agent covering all three options. At most three turns are allowed. If none reaches unanimous acceptance, deterministic fallback recommends a validated plan and logs why.

Previewing never chooses or executes a plan. A human may select any hard-valid alternative, including one with efficiency objections. The audit identifies that choice separately from agent consensus. Hard-constraint vetoes cannot be overridden.
